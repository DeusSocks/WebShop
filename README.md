# 🛒 E-Commerce Scraper & Web Catalog

Пет-проект для автоматического сбора данных о товарах из интернет-магазина, их сохранения в базу данных и отображения через веб-интерфейс и REST API.

## 📋 О проекте

Система работает в три этапа:
1. **Парсинг:** Скрипт запрашивает HTML-страницы магазина, извлекает названия, цены, описания и ссылки на товары.
2. **Хранение:** Собранные данные валидируются и сохраняются (или обновляются) в реляционной базе данных.
3. **Отображение:** Веб-приложение на FastAPI отдает данные клиенту в виде готовых HTML-страниц или JSON-ответов.

## 🛠 Стек технологий

* **Парсинг:** `requests`, `beautifulsoup4`
* **База данных и ORM:** `SQLAlchemy` (SQLite / PostgreSQL)
* **Бэкенд и API:** `FastAPI`, `Uvicorn`
* **Шаблонизация (опционально):** `Jinja2`

## 🏗 Структура проекта

```text
├── app/
│   ├── main.py          # Точка входа FastAPI и роуты
│   ├── database.py      # Подключение к БД и настройка сессий

│   ├── schemas.py       # Pydantic схемы для валидации
│   └── templates/       # HTML-шаблоны для фронтенда
├── scraper/
│   └── parser.py        # Логика парсинга магазина и записи в БД
├── requirements.txt     # Зависимости проекта
└── README.md
```

## 🚀 Установка и запуск

### 1. Клонирование репозитория и настройка окружения

```bash
git clone <url-вашего-репозитория>
cd <название-папки>

python -m venv venv
# Для Linux/macOS:
source venv/bin/activate
# Для Windows:
venv\Scripts\activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск парсера

Перед запуском веб-сервера наполните базу данных актуальными товарами:

```bash
python scraper/parser.py
```

### 4. Запуск веб-приложения

```bash
uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресам:
* **Веб-интерфейс:** `http://127.0.0.1:8000`
* **Документация API (Swagger):** `http://127.0.0`

## 🔌 Основные эндпоинты

| Метод | URL | Описание |
| :--- | :--- | :--- |
| `GET` | `/` | Главная страница со списком спарсенных товаров |
| `GET` | `/api/products` | Получить список всех товаров в формате JSON |
| `GET` | `/api/products/{id}` | Получить детальную информацию о товаре по ID |
| `POST` | `/api/scrape` | Запустить принудительное обновление данных (парсинг) |
